# Simple Bash Utils

Реализация утилит **cat** и **grep** на языке C с поддержкой основных флагов GNU/Linux.

Проект был выполнен в рамках изучения системного программирования, работы с файлами, аргументами командной строки и стандартными Unix-утилитами.

---

## Функционал

### s21_cat

Аналог команды `cat`.

Поддерживаемые флаги:

- `-b` — нумерация только непустых строк
- `-n` — нумерация всех строк
- `-s` — удаление повторяющихся пустых строк
- `-e` — отображение символа `$` в конце строки + поведение `-v`
- `-E` — отображение `$` в конце строки
- `-t` — отображение табов как `^I` + поведение `-v`
- `-T` — отображение табов как `^I`
- `-v` — отображение непечатаемых символов

Пример запуска:

```bash
cd src/cat
make
./s21_cat -n test.txt
```

---

### s21_grep

Аналог команды `grep`.

Поддерживаемые флаги:

- `-e pattern` — поиск по шаблону
- `-i` — игнорирование регистра
- `-v` — инверсия поиска
- `-c` — вывод количества совпадений
- `-l` — вывод только имен файлов
- `-n` — вывод номера строки
- `-h` — скрыть имя файла
- `-s` — скрыть ошибки
- `-f file` — чтение шаблонов из файла
- `-o` — вывод только совпавших частей строки

Пример запуска:

```bash
cd src/grep
make
./s21_grep "hello" test.txt
```
